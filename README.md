# Hotel Booking Classification

## 📌 Project Overview

This project uses Machine Learning to predict whether a hotel booking will be **cancelled or not**.

The project uses the **Hotel Booking Demand dataset** and applies data preprocessing, exploratory data analysis, feature encoding, feature scaling, and Logistic Regression for classification.

## 🎯 Objective

The main objective is to predict the `is_canceled` value:

- `0` → Booking is not cancelled
- `1` → Booking is cancelled
